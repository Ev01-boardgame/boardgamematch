BGG 官方主題／機制 → 六軸 delta（v1）

左側為 BoardGameGeek browse 頁上的全部 Categories 與 Mechanics（站內快照：public/data/bgg-taxonomy.json）。右側六欄為加總修正量（delta）（優先 GET /api/bgg-axis-deltas，否則 bgg-axis-deltas-v1.js），與掃描頁 applyDeltasForTags 比對規則一致（先精確小寫名，僅一個命中時才用子字串近似）。

delta 會加在由 complexity 等算出的基底六軸上，再 clamp 到 0–12；未顯示數字表示 v1 尚未為該標籤設定 delta。

六軸欄位說明

BGG Categories（官方主題，全表）

名稱與 BGG 官網一致；資料庫／Jina 常為小寫英文，比對時會正規化。若 BGG 新增分類，請更新快照並執行 node scripts/build-bgg-taxonomy.mjs。

BGG Mechanics（官方機制，全表）

與遊戲 XML／頁面上的 Mechanic 名稱一致。delta 鍵名多為小寫（例如 deck building 對應官網 “Deck, Bag, and Pool Building” 可能顯示「未設定」，請至 delta 編輯器 線上新增或改靜態檔）。
