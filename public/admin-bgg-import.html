BGG 匯入工具（僅本機預覽＆下載，不寫入資料庫）

上傳從 BGG 或外部工具匯出的遊戲清單 CSV，轉成接近 game_database 的欄位格式，並加上 8 軸預設值。

這個頁面目前只會在瀏覽器本機運算與下載檔案，不會呼叫 Cloudflare API，也不會改動線上資料庫。

1️⃣ 上傳 BGG collection CSV（或任何含 BGG ID 的清單）

目前預期格式：第一行為標題列，至少需要一個能對應到 bgg_id / objectid 的欄位。 若有 name / objectname、year / yearpublished、minplayers / maxplayers、 playingtime / minplaytime / maxplaytime、avgweight 等欄位，會一併解析成對應欄位。 欄位名稱不完全一致也沒關係，工具會嘗試以關鍵字對應。
尚未載入檔案
解析完成後，可在下方預覽與下載「轉換後 CSV」，再決定是否進一步匯入資料庫。

2️⃣ 解析與欄位對應紀錄

[系統] 請先選擇一個 CSV 檔案，上傳後再按「解析並轉成內部格式」。

3️⃣ 預覽轉換結果 & 下載 CSV

轉換後欄位包含：bgg_id, name_en, year, min_players, max_players, min_playtime, max_playtime, playing_time, complexity, image_url， BGG 數值欄位（baverage, rank, bggbestplayers, bgglanguagedependence, itemtype, bgg_type）， category, mechanics，以及 axis_entry ... axis_competition 六個新版維度（目前為預設估值，可之後再調整）。
尚無資料，請先上傳並解析 CSV。
