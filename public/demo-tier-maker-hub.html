🥇 桌遊 Tier Maker — 離線示範（多版本）

參考 SuperFola/TierListMaker （純前端、拖曳、匯出圖）與 danbugs/tiermaker-template-generator （名稱疊圖、批次產素材）的思路，先做出可本機開啟的原型；之後再接 D1（users 收藏／清單、game_database 等）。

V1 · 主規格（D1 + Tier 背景 + 每格封面）

D1 搜尋、Tier 整張背景、封面顯示四模式（同 poster）、每格 ⚙ 自訂；無命中時假封面。待分區不匯出。

開啟正式頁（V1）

維護請改 tier-maker.html。舊離線單檔 demo-tier-maker-v1-image.html 僅備份，可刪。

V1b · 封面進階（色相／自訂色）

同 V1，另加漸層色相滑桿、自訂純色預設，方便試視覺再決定正式站規格。

開啟 V1b

V2 · 文字桌遊卡（模擬玩家資料）

內建「擁有／想玩／自訂清單」假資料，以遊戲名 chip 拖入 Tier；適合對齊本站遊戲名與收藏。

開啟 V2

V3 · 混合 + localStorage（模擬 D1）

一鍵載入模擬 API JSON、手動加遊戲、存檔／還原；展示未來如何接真實 API。

開啟 V3

V4 · 名稱圖卡批次（danbugs 路線）

多行遊戲名 → 各產一張方塊圖（名稱疊在底圖上），方便丟到 V1 或外站用。

開啟 V4

正式站占位：tier-maker.html
