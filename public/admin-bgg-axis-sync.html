BGG ID 掃描 · Category／Mechanic → 六軸補齊

依 BGG ID 由小到大 逐筆檢查：是否已收錄於 game_database。xmlapi2/thing（Worker → Jina 備援）可取得：category／mechanic 官方名稱（<link type="boardgamecategory|boardgamemechanic">）、min／max playtime、年份、人數、複雜度、圖片、subdomain 類型等。Jina 讀 HTML僅作備援（封面、thing 失敗時的標籤／數值補洞）。六軸仍依標籤＋複雜度對照表計算。

未收錄則以 thing 為主建立新遊戲並帶入六軸。請分段設定 ID 範圍，避免一次掃過大區間。

玩家簡易建檔：使用者在「編輯桌遊收藏」用 BGG 選遊戲並儲存時，會在 game_database 寫入最小列（bgg_id＋名稱），欄位 ingest_source = user_collection。 掃描該 ID 時 log 會出現 📌 提示；請照常跑掃描以補齊 thing／category／六軸（與一般建檔相同流程，不會在儲存收藏時卡住）。

API 連線（本機開發）

若用 Live Server（例如 http://127.0.0.1:5500）開此頁，預設會請求 /tables/... 而得到 404。 請填正式站網域作為基底（勿結尾斜線），並在連正式站 API 時填入與後端相同的 X-Api-Key（Worker 的 API_SECRET）。 同源在正式站操作時可留空。跨域需 Worker 的 ALLOWED_ORIGINS 含本機 origin 並重新部署。
