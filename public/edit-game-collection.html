🧩 從 BoardGameGeek 匯入收藏

僅讀取你在 BGG 上公開的「擁有」與「願望清單」。我們不會索取你的 BGG 密碼；若 collection 設為私密則無法讀取。 匯入與現有清單為聯集（只新增、不刪除既有項目）。預覽需已登入（帶 JWT）。 按「儲存變更」時：凡帶 BGG ID 的項目會先寫入站內 game_database 的簡易建檔（僅 id／名稱，標記 ingest_source=user_collection），並盡量自 pending 移除；後台再以「BGG 六軸掃描」依同一 BGG ID 補齊 thing／category／六軸，無需在儲存時等待完整建檔。 預覽視窗內請按「確認匯入至清單」，再按本頁下方「儲存變更」，資料才會寫入伺服器。

首次使用待對照 ID 請在 D1 執行 migration：20260326_users_bgg_collection_pending.sql
